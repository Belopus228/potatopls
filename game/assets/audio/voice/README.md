# Озвучка реплик

Сюда кладутся записи реплик: `<ключ>.mp3`. Ключ — первые 12 знаков md5 от строки «кто|текст»
(считает `tools/voice/extract_lines.py`, в игре — `Snd.voice_key`). Список всех реплик с ключами —
`tools/voice/lines.json`.

Записи делает `tools/voice/fish_tts.py` через Fish Audio: голоса задаются в `tools/voice/voices.json`,
ключ API — в секрете репозитория `FISH_API_KEY`. Реплика без записи просто идёт без голоса.
Свою запись можно положить и руками: имя файла — ключ реплики, формат MP3.

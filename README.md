# Меллстройность 3D

Фанатская 3D-игра от третьего лица по мотивам мемов: Ч, Друн, Брал, Дод, Тёмный Друн и ФОГ; общага, Мурино, село Молочное,
Мытищи, Банька и Жмурино. Драки, боссы, побочные задания, магазины, головоломки, сохранения.

В репозитории две версии игры:

| | Версия 2 (основная) | Версия 1 |
|---|---|---|
| Движок | Godot 4.4.1 | three.js, один HTML-файл |
| Где лежит | [`game/`](game) | [`docs/index.html`](docs/index.html), исходники в `src/` |
| Графика | готовые 3D-модели и анимации (CC0) | всё рисуется кодом |
| Платформы | Windows, Android, Linux, браузер | браузер |
| Глав и боссов | 7 и 7 | 6 и 6 |

## Версия 2: скачать и запустить

Сборки лежат в релизе [**v2-latest**](https://github.com/Belopus228/potatopls/releases/tag/v2-latest). Он пересобирается
автоматически после каждого изменения в `game/`.

| Платформа | Файл | Как запустить |

| Linux (x86-64) | [`Mellstroynost-3D-linux.zip`](https://github.com/Belopus228/potatopls/releases/download/v2-latest/Mellstroynost-3D-linux.zip), 62 МБ | Распаковать, запустить `./Mellstroynost-3D.x86_64`. |

Нужна видеокарта с OpenGL 3.3 (ПК), OpenGL ES 3.0 (телефон) или браузер с WebGL 2.

### Управление

| Действие | Клавиатура и мышь | Геймпад | Телефон |
|---|---|---|---|
| Ходьба, бег | `WASD` или стрелки, `Shift` | левый стик, нажать стик | стик слева, до упора — бег |
| Камера | мышь, колесо — приближение | правый стик | вести пальцем справа |
| Удар (серия из трёх) | левая кнопка мыши или `J` | X | УДАР |
| Прыжок | `Пробел` | A | ПРЫЖОК |
| Перекат (неуязвимость) | `C` или колёсико | B | КАТ |
| Бросить котлету денег | правая кнопка мыши или `F` | RB | ₽ |
| Действие, разговор | `E` | Y | E |
| Дихлофос (держать) | `Q` | LB | ПШИК |
| Ульта «АМ-АМ-АМ», когда ярость полная | `R` | RT | АМ! |
| Съесть еду | `1` | крестовина вверх | ЕДА |
| Рюкзак, пауза | `Tab`, `Esc` | Back, Start | РЮКЗАК, II |

В настройках: три уровня графики, чувствительность и инверсия камеры, громкость музыки и звуков, тряска камеры,
сенсорные кнопки, счётчик кадров, полный экран.

### Главы

1. **Общага** — записка коменданта, код от подвала, Крысиный Король.
2. **Мурино** — двор-узел: Друн и шаверма, курьер и посылка, «ливт» с головоломкой, Тёмный Друн на крыше П-46, станция «поеза».
3. **Молочное** — кондукторша и Дед, сарай и гнездо паучностей, трансформатор, трамвай в Паучью яму, Паучья Матка.
4. **Мытищи** — санпропускник, три куска мыла, душевые, Дворец Чистоты и Мойдодыр.
5. **Банька** — Пра Дод, дрова и веник, остров за тонким льдом, парная, Банник.
6. **Жмурино** — сторож, три свечи, склеп с кодом, казино «Бурмалда», Консьерж.
7. **Первый этаж** — ФОГ и титры. Есть секретная концовка: для неё нужна пятая кнопка из казино.

Из глав 3–6 «поез» возвращает в Мурино. Прогресс сохраняется на контрольных точках; пройденные главы можно переиграть.
Сохранение лежит в папке пользователя Godot (`user://save.json`), в браузере — в хранилище сайта.

### Чего в версии 2 нет и что не проверено

- Игру проходит автомат (см. «Проверка сценариями»), а не человек. Баланс боёв подобран по этому автомату, на живого игрока его никто не примерял.
- Музыка и звуки синтезированы скриптом. В среде, где шла разработка, их нельзя было послушать: проверены только уровень громкости, спектр и стык петли.
- Сборки делает GitHub Actions. Linux-сборку он запускает без окна и прогоняет на ней короткий сценарий; сборки под Windows и Android не запускал никто, сенсорное управление на настоящем телефоне не пробовали.
- Глазами проверена только браузерная сборка, по снимкам экрана из браузера без видеокарты. Скорость на настоящем железе не измерялась.
- APK подписан отладочным ключом.

### Для разработки

Открыть папку `game/` в [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/) (обычная версия, не .NET) и нажать F5.

```bash
# проверка сценариями: автомат проходит все главы без окна, около минуты
godot --headless --fixed-fps 60 --path game -- --nosave --test=smoke,dorm,murino,milk,myt,banya,jmur,final

# бой автомата с одним боссом и сводка для баланса: rat, dark, mother, moidodyr, bannik, concierge, fog
godot --headless --fixed-fps 60 --path game -- --nosave --test=_boss --boss=bannik

# экспорт (нужны шаблоны экспорта 4.4.1)
godot --headless --path game --export-release "Web" out/web/index.html
node tools/serve_web.mjs out/web          # http://localhost:8060
```

Параметры запуска (после `--`, в браузере — в адресе после `?`): `lv=<глава>` и `cp=<точка>` — начать с главы
(`dorm`, `murino`, `milk`, `myt`, `banya`, `jmur`, `final`), `fresh` — новое сохранение, `nosave` — не писать сохранение,
`god` — бессмертие, `q=0..2` — графика, `touch` — сенсорные кнопки на ПК, `skip` — пропускать сценки, `fps` — счётчик кадров.

**Проверка сценариями.** `game/tests/*.gd` — сценарии: автомат проходит каждую главу от начала до конца (маршруты пешком,
задания, головоломки, бои с боссами). Сейчас это 127 проверок. В последнем прогоне автомат сам победил всех семерых
боссов; если он проигрывает бой, сценарий добивает босса служебной командой и идёт дальше, так что «зелёный» прогон
не доказывает, что каждый бой проходим. Список для CI — в `game/tests/ci.txt`. Сборку, проверку и выкладку релиза делает `.github/workflows/build.yml`.

**Структура `game/`:**

- `src/core/` — состояние игры и сохранения (`g.gd`), ввод (`inp.gd`), звук (`snd.gd`).
- `src/actors/` — модели и позы, игрок, враги, NPC, снаряды, общий класс босса; `src/bosses/` — семь боссов.
- `src/world/` — конструктор уровней (`level.gd`), окружение, материалы, эффекты, камера, предметы, ящики, двери.
- `src/ui/` — интерфейс, HUD, сенсорные кнопки, меню, головоломки; `src/data/` — предметы, персонажи, бестиарий.
- `src/levels/` — главы; `src/test/t.gd` и `tests/` — сценарии и автомат для боёв.
- `assets/` — модели, шрифты, текстуры, портреты, звук. Откуда что взято и лицензии: [`game/CREDITS.md`](game/CREDITS.md).

**Инструменты:** `tools/assets/` — загрузка и подготовка моделей, генерация текстур; `tools/audio/make_audio.py` — синтез
всей музыки и звуков (Python, numpy, soundfile); `tools/serve_web.mjs` — сервер для браузерной сборки.

## Версия 1 (three.js)

Вся игра — один файл [`docs/index.html`](docs/index.html) (около 0,9 МБ): движок, уровни, текстуры, звук и музыка внутри,
интернет не нужен. Шесть глав, шесть боссов. Работает в браузере на ПК и на телефоне.

- **Проще всего:** скачать [`docs/mellstroynost-3d.zip`](docs/mellstroynost-3d.zip) (320 КБ), распаковать и открыть
  `Mellstroynost-3D.html` двойным щелчком в Chrome, Edge, Firefox или Safari (нужен WebGL 2).
- **Локальный сервер:** `npm run serve` → <http://localhost:8080>.
- **GitHub Pages:** включить в настройках репозитория Pages из папки `/docs`.

```bash
npm install
npm run build   # src/ -> docs/index.html (three.js + esbuild, всё в одном файле)
npm run dev     # пересборка при изменениях + сервер на :8080
npm run pack    # сборка + архив docs/mellstroynost-3d.zip
npm install --no-save puppeteer-core @sparticuz/chromium && npm test   # автотесты в headless-Chromium
```

Управление то же, что в версии 2. Параметры адреса: `?q=0..3` — качество, `?touch` — сенсорное управление на ПК,
`?lv=<глава>&cp=<точка>` — начать с главы (`dorm`, `murino`, `milk`, `myt`, `banya`, `final`), `?god` — бессмертие.

Исходники: `src/*.js` и `src/levels/*.js`, сборка — `tools/build.mjs`, тесты — `tools/test/`.

# Меллстройность 3D

Фанатская 3D-игра от третьего лица по мотивам мемов: Ч, Друн, Брал, Дод, Тёмный Друн и ФОГ; Мурино, село Молочное, Мытищи и Банька.
Шесть глав, шесть боссов, побочные задания, магазины, головоломки, сохранения. Работает в браузере на ПК и на телефоне.

Вся игра — **один файл** [`docs/index.html`](docs/index.html) (около 0,9 МБ): движок, уровни, текстуры, звук и музыка внутри, интернет не нужен.

## Как запустить

- **Проще всего:** скачать архив [`docs/mellstroynost-3d.zip`](docs/mellstroynost-3d.zip) (320 КБ), распаковать и открыть `Mellstroynost-3D.html` двойным щелчком в Chrome, Edge, Firefox или Safari (нужен WebGL2). Это тот же файл, что и `docs/index.html`.
- **Локальный сервер:** `npm run serve` → <http://localhost:8080>.
- **GitHub Pages:** в настройках репозитория включить Pages из папки `/docs` — игра откроется по адресу `https://<user>.github.io/potatopls/`.
- **Телефон:** открыть ту же страницу и повернуть телефон горизонтально; сенсорное управление включится само.

## Управление

| Действие | Клавиатура и мышь | Телефон |
|---|---|---|
| Ходьба | `WASD` / стрелки | стик в левой половине экрана |
| Бег | `Shift` | тянуть стик дальше |
| Камера | мышь, колесо — зум | правая половина экрана |
| Прыжок | `Пробел` | ⤒ |
| Удар (серия из трёх) | ЛКМ / `J` | 👊 |
| Бросить котлету денег | ПКМ / `F` | 💸 |
| Перекат (неуязвимость) | `C` / колёсико | 💨 |
| Действие, разговор | `E` | кнопка с подсказкой |
| Дихлофос | `Q` (держать) | 🧴 |
| Ульта «АМ-АМ-АМ» | `R`, когда ярость полная | 😱 |
| Съесть еду | `1` | кнопка внизу по центру |
| Инвентарь | `Tab` / `I` | 🎒 |
| Пауза | `Esc` / `P` | ⏸ |

Геймпад тоже поддерживается. Качество графики (4 уровня), громкость и чувствительность камеры меняются в настройках.

## Главы

1. **Общага** — записка коменданта, код от подвала, Тараканий Царь.
2. **Мурино** — хаб: Друн и ульта, курьер, «ливт» с головоломкой, Тёмный Друн на крыше, станция «поеза».
3. **Молочное** — дед и огород, трансформатор, трамвай, Паучья Матка.
4. **Мытищи** — Дворец Чистоты, головоломка с мылом, Мойдодыр.
5. **Банька** — дрова и веник, печь, Банник на озере.
6. **Финал** — ФОГ.

Прогресс сохраняется на контрольных точках (в `localStorage` браузера). Пройденные главы можно переиграть из меню.

## Сборка

```bash
npm install
npm run build   # src/ -> docs/index.html (three.js + esbuild, всё в одном файле)
npm run dev     # пересборка при изменениях + сервер на :8080
npm run pack    # сборка + архив docs/mellstroynost-3d.zip
```

Архив можно выложить на [tmpfiles.org](https://tmpfiles.org/) автоматически: это делает задача GitHub Actions `.github/workflows/upload-tmpfiles.yml`
(запускается при обновлении архива в рабочей ветке или вручную), ссылка появляется в Summary запуска. Ссылки tmpfiles.org живут 60 минут.

Параметры адреса для отладки: `?q=0..3` — качество, `?touch` — сенсорное управление на ПК, `?lv=<глава>&cp=<точка>` — начать с главы
(`dorm`, `murino`, `milk`, `myt`, `banya`, `final`), `?god` — бессмертие, `?nodyn` — без авто-разрешения.

### Структура

- `src/main.js` — вход и главный цикл; `src/gfx.js` — рендер, небо, свет, блум, уровни качества; `src/tex.js` — процедурные текстуры и материалы.
- `src/world.js`, `src/level.js`, `src/kit.js` — коллизии, сборка уровня, конструктор окружения; `src/rig.js` — персонажи и анимации.
- `src/player.js`, `src/camera.js`, `src/input.js`, `src/actors.js`, `src/bosses.js` — игрок, камера, ввод, враги, боссы.
- `src/game.js`, `src/ui.js`, `src/script.js`, `src/puzzles.js`, `src/items.js`, `src/audio.js`, `src/fx.js` — сохранения и сценарии, интерфейс, головоломки, предметы, синтез звука, частицы.
- `src/levels/*.js` — главы; `assets/faces/*.jpg` — лица персонажей (встраиваются в сборку).

### Автотесты

Игра проходится скриптом в headless-Chromium (WebGL через SwiftShader): полное прохождение, пешие маршруты, бои с боссами, меню, сохранения, звук, геймпад, утечки памяти.

```bash
npm install --no-save puppeteer-core @sparticuz/chromium   # или CHROME_PATH=/путь/к/chrome
npm run build && npm test
```

## Дисклеймер

Некоммерческая фанатская пародия. Все совпадения — шутка. Музыка, звуки и почти вся графика сгенерированы кодом.
Лица персонажей в `assets/faces/` — кадры из открытых источников; при желании их можно заменить своими картинками 256×312 и пересобрать игру.
